## 五、综合判断规则

| 触发条件 | 仓位操作 |
|----------|---------|
| 所有维度 🟢 | 仓位上限 100%，单票≤15% |
| 1个维度 🟡 | 不管，正常持仓 |
| 2个维度 🟡 | 仓位从 100% → 70%，持有标的减到5只 |
| 3个维度 🟡 | 仓位从 70% → 30%，只留最核心3只 |
| 任1个维度 🔴 | 仓位降到 10%，清仓所有弹性票 |
| 估值+情绪同时 🔴 | 空仓。这是大顶。 |
