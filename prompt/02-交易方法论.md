# 02 · 交易方法论

> 本册是**规则层**，与软件架构解耦。
> 如果你有自己的一套方法，**只需替换本册，01 册的架构完全不用动**。
> 下面给出的是原系统作者的完整方法与默认参数，可直接用，也可当作示例改写。

---

## 零、方法论的三个前提

**前提一：只做右侧。**
不接下跌中的飞刀。价格必须先证明自己（站上结构颈线），才谈买入。左侧下跌途中，系统一个"买"字都不说。

**前提二：结构 = 两条线。**
任何形态（W 底、头肩底、平台整理）在这套系统里都被翻译成**两个数**：

- **颈线**：形态的突破位。站上它 = 结构激活。
- **量度目标**：形态高度向上投射的目标价。它定义了"这一轮该走多远"。

一旦这两个数确定，"何时入、何时减、何时离"全部变成纯数学。**人只负责画这两条线，剩下交给系统。**

**前提三：自上而下。**
个股不能单独决定入场，必须过指数这一关。指数是大盘的季节，个股是季节里的花。

## 一、方向标签：战略层（人工设定）

每个标的必须有一个方向标签，**由人设定，压制系统的一切自动判断**。

| 标签 | 判定含义 | 系统行为 |
|---|---|---|
| **右侧** | 结构进行中，价格在有效结构之上运行 | 完整规则激活：完成度、阶梯减仓、移动止盈 |
| **筑底** | 已跌到位、进入起涨区或平台，正在等形态 | 只盯形态，**不产生任何买入建议** |
| **左侧** | 结构已衰竭，仍在回落途中 | 规则全部休眠，只显示"距起涨区还有多远" |
| **未定** | 尚未表态 | 不参与统计 |

**为什么标签必须压制系统判断**：结构状态机看到"价格在颈线上方"就想判"进行中·完成度 x%"，但你可能明知这是一轮已经走完的行情在反弹。**你的眼睛比状态机的除法更懂市场。**

**唯一的自动流转**：收盘进入你自己划的回撤区/起涨区，或触及你自己设的哨兵 → 自动转筑底。因为这一步不含任何行情判断，纯粹是"价格到了你自己指定的位置"。

## 二、入场：共振闸门

### 2.1 三个条件同时成立才入场

```
① 个股收盘价 > 颈线            （结构激活）
② 主关联指数方向标签 = 右侧     （大盘许可）
③ 该轮结构此前未入场            （去抖）
```

只有 ① 没有 ②：系统提示"个股已突破，等待指数右侧"，**不放行**，标的进「突破确立·待共振」清单等着。

### 2.2 指数晚期减配（重要的风控设计）

主指数虽然是右侧，但**它自己也走了很远**的时候，个股突破的赔率变差了。

| 主指数量度完成度 | 个股突破入场仓位 |
|---|---|
| < 90% | **满仓**（含融资）+ 期权腿（如有备注） |
| ≥ 90% 或已兑现 | **半仓**（50%），提示标注"指数晚期·半仓入场" |
| 未录价位（完成度不可算） | 满仓，标注"指数完成度未知" |

后续的阶梯减仓与止盈按实际入场仓位比例执行。

### 2.3 入场提示内容

必须包含：突破幅度、主指数状态、**"满仓满融"或"半仓"字样**、该标的的期权/融资备注原文。

## 三、持有期：分段减仓阶梯

按**个股自身**的量度完成度分档减仓。核心思想：**越接近目标，仓位越轻**——绝不满仓拿到最高点。

| 完成度 | 动作 | 剩余仓位 |
|---|---|---|
| ≥ 70% | 首次减仓 | 剩 70% |
| ≥ 80% | 再减 | 剩 50% |
| ≥ 90% | 再减 | **剩 25%**（区间 20–30% 可调） |
| 触及量度目标（100%） | 按主指数完成度终减 | 见下表 |

**触及目标时的终减档位**（看主指数走到哪了）：

| 主指数完成度 | 剩余仓位 | 逻辑 |
|---|---|---|
| ≥ 90% 或已兑现 | 剩 10% | 大盘也到顶了，砍到只剩底仓 |
| 70–90% | 剩 15% | |
| < 70% | 剩 20% | 大盘还有空间，多留一点 |
| **主指数结构已衰竭** | **剩 10%（最激进档）** | 大盘走完第一程回落 = 最危险环境 |

**为什么留一点不清光**：量度目标满足后仍可能有第二波主升，留 10–25% 博更大涨幅，风险由移动止盈兜底。

## 四、离场：三条退路

**谁先到走谁。**

### 4.1 移动止盈（主力防线）

- **自该轮最高收盘价回撤 ≥20% → 剩余全部清仓**（P1 警报）
- **启用条件**：完成度首次 ≥70% 之后才生效
  - 为什么设启用条件：主升浪初期一次正常洗盘经常 -15~20%，过早启用会被洗出去。初期防守交给假突破线。
- 触发后标的转入观察池（结构未破坏，可录回撤买入区转入回撤关注池）

### 4.2 假突破清仓（早期防线）

- **收盘价 < 颈线 × 0.95 → 全部清仓**（P1 警报）
- 只在**持有状态**生效
- 典型场景：W 底突破后又跌回颈线下方 —— 经典骗炮形态，毫不犹豫走人
- 非持有状态跌回颈线：不报警，只是状态转为"突破失败·等待重新站上"，等重新站上还能再入场

### 4.3 头部确立（人工判断）

**系统永不自行判定头部**，流程是：

1. 你在图上画出头部颈线（头肩顶/双头的颈线），确认时二选一：
   - **「立即确认头部」**：直接触发 P1 清仓提示
   - **「先观察」**：挂顶部观察哨线，收盘跌破该线 → P1 警报"头部颈线跌破，确认清仓？"
2. 你点确认 → 清仓 → 战役归档
3. 归档与标的去向解耦：可选转入观察池，或录回撤买入区转入回撤关注池

**自动辅助**：任何持仓标的完成度 ≥90% 或触及目标当日，系统推卡"已进入量度满足区，开始留意头部形态"，标的挂"顶部观察中"徽章 —— **提醒你该去看图找头了**。

## 五、结构走完之后：三条路

第一轮结构衰竭（已兑现 ≥90% 后回撤 ≥15%）之后，一只票只有三种未来。**必须由你选型**，系统按新颈线相对第一轮区间的位置给建议。

### 路 A · 浅回撤候买回

**场景**：只回撤一部分，大结构未坏。
**做法**：录「回撤买入区」（上下沿）+ 买回成数，`zone_mode = buyback`。
**触发**：收盘进入买入区 → 提示"回撤到位，买回 N 成"。
**逆共振警示**：主指数处于高位时，提示照发但标红警示（提示不拦截）。
**失效**：收盘 < 买入区下沿 × 0.95 → "买点作废"，退回观察池。

### 路 B · 深蹲候形态（左侧 → 右侧）

**场景**：大回撤跌回起涨区，需要重新筑底。
**做法**：录「起涨区」（默认预填 = 第一轮颈线 ~ 颈线×1.1），`zone_mode = pattern`。
**关键**：到了起涨区**也不买**，先等形态。

```
左侧回落中 → 系统全程静默（一个"买"字都不说）
      ↓ 收盘进区
自动转筑底 + 提示"到达起涨区，开始盯形态"
      ↓ 你看出 W 底/头肩底，画新一轮颈线与目标
      ↓ （目标默认预填 = 前一轮峰值）
转入就绪池，走正常共振入场流程
```

### 路 C · 新高突破（纯右侧）

**场景**：只整理不深跌，买点在**上方**。
**做法**：录第二轮结构，颈线 ≈ 前高或平台上沿，目标 = 新的量度投射。
**候场指标**：距突破位 +x%（向上），≤3% 进日报第 2 档。
**触发**：收盘站上新颈线 + 主指数右侧 → 入场。

## 六、筑底 → 右侧：三个可量化的候选判据

**系统不自行认定筑底完成**，但可以帮你把候选摆出来。命中任一即推"疑似筑底完成，请复核"，**你点确认才转右侧**。

| # | 判据 | 说明 |
|---|---|---|
| ① | **收盘站上你新画的颈线** | 最直接 |
| ② | **缩量企稳后放量阳线** | 近 N 日均量低于前 M 日均量 x% 之后，出现放量倍数 ≥k 的阳线（均量计算不含当日，否则放量当天自己抬高基准） |
| ③ | **二次探底不破前低** | 前低 = 进区以来最低收盘；要求前低之后有像样反弹、且当日不跌破前低 |

三项独立开关，参数全部可调。"维持筑底"之后同一判据不再刷卡，出现新判据才再提示一次。

## 七、哨兵：反转预警

在关键位埋的"地雷"，**只提醒，永不自动改标签**。

- 每标的 ≤2 条，可一键引用既有价位（起涨区上下沿 / 颈线 / 前高 / 失效线）
- 距离 ≤5% 进日报第 3 档，≤3% 进第 2 档并触发加推
- 显示"距哨兵 x% · 按近 20 日日均波幅约 N 天路程"
  - 这是"提前几天提醒"在数学上最诚实的表达 —— 系统无法预知天数，但能把距离换算成路程
- 收盘穿越 → P2 提醒 + 待办"是否更新方向标签"

---

## 八、质地评分：只排序，不触发

六维自动评分（数据源：财务接口），A–D 档：

```
PEG（PE-TTM ÷ 净利同比增速）      ← 唯一带价格分量，每交易日更新
营收同比 / 净利同比 / ROE
毛利率趋势 / 业绩预告方向          ← 季报驱动，周更 + 财报季每日扫描
```

**铁律**：质地分只影响排序与关注度，**永不触发任何买卖信号**。
结构说了算 —— A 级的票也得等底部形态，C 级的票到了清仓线照样走。

## 九、账本：只记模拟，不记真实

**这是一个重要的产品决策，值得解释。**

早期版本同时记录"真实战役"（你实际的操作）和"模拟战役"（规则全执行会怎样）。结果是：**你不会每次操作后都回来点一下**，真实账本永远是残缺的，摆出来只会天天跟模拟"对不上号"，制造困惑。

终态：**全站只有模拟账**。

- 信号弹出来 → 你点「知道了」消卡，不需要汇报执行结果
- 池子流转改为信号触发时自动完成，你实际没买就手动拖出持有池
- 模拟收益回答的是：**"这套规则在这只票上值多少钱"** —— 这才是辅助判断需要的信息

保留的人工确认动作（因为它们驱动系统状态，不是记账）：头部确认、候场选路、方向标签、哨兵复核、指数标签建议。

## 十、参数总表（默认值）

全部参数进设置页，可随时调整。

| 参数 | 默认 | 说明 |

| 失效线系数 | 0.95 | 失效线 = 颈线 × 该值 |

### 入场

| 参数 | 默认 | 说明 |
|---|---|---|

| 晚期减配比例 | 50% | 半仓入场 |

| 参数 | 默认 | 说明 |

## 十一、一只股票的完整一生（串起来看）

```
【建档】   批量导入或手动添加 → 观察池 · 方向未定
              ↓
【画线】   你看出 W 底 → 画颈线 + 量度目标 → 确认写入
              ↓  标签设为「筑底」或「右侧」
【等待】   系统每日收盘比对，什么都不做
              ↓  收盘站上颈线
【入场】   主指数右侧？ → 是：满仓/半仓入场提示，进持有池
                          否：进「待共振」清单，继续等
              ↓
【持有】   完成度 70/80/90 三档减仓提示
           完成度 ≥90% → 推"开始留意头部形态"
              ↓
【离场】   移动止盈（自峰值 -20%） 或 假突破（颈线-5%） 或 你确认头部
              ↓
【归档】   本轮模拟收益落账，结构标记衰竭
              ↓
【选路】   A 浅回撤候买回 / B 深蹲候形态 / C 新高候突破
              ↓
        （回到画线，开始第二轮）
```
