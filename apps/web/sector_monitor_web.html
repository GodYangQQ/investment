板块划线看盘

这套 Web 看盘和 run/soxx_monitor.py 的画线逻辑一致：
· 水平线：点按钮后点图上任意位置放置；趋势线：点第一个点 → 移动预览 → 点第二个点完成。
· 再点一次按钮、按 Esc 或右键 → 退出画线模式。
· 左键点线（8px 内）选中；选中后拖线体平移，拖两端圆点调整；点空白取消。
· Delete / Backspace 删除选中线；Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做。
· 颜色含义：当前价在线上方 = 支撑（绿）； 在线下方 = 压力（红），随价格实时重算。
· 线条按「市场:板块代码|周期」保存到 data/sector_lines.json，重启浏览器/服务都保留； 数据结构与 Qt 版相同（h: y / trend: x1,y1,x2,y2）。
· 图表操作：左键拖拽平移（X+Y）、滚轮缩放（自动适配 Y 轴）、中键平移、双击/「重置视图」恢复。
· 自选：左侧点 ☆ 收藏，右侧「自选」抽屉看迷你图 + 已画线；卡片显示最近的下支撑 / 上压力， 点卡片切换板块，「放大」看单图专注模式（Esc 退出）。

板块口径：A股用东财行业/概念板块，按成交额排序，可切量比、主力净额与涨幅； 美股用 SPDR 11 大行业 + 半导体/科技 + 主题 ETF。列表每 10 秒刷新，分时/日线按周期自动更新。
