# 股票交易模拟游戏

## 快速开始

```bash
cd stock_game
pip install flask numpy matplotlib

# Web版
python app.py
# 浏览器打开 http://localhost:5123

# 桌面版
python game_app.py
```

## 功能

- **K线图**：蜡烛图 + MA5/10/20/30/60 + 成交量 + B/S标记
- **交易**：按手买入/卖出，快捷全仓/半仓/1/3/1/4
- **手续费**：佣金万2.5(最低5元) + 卖出印花税千1
- **多股票**：游戏中途可添加/删除股票
- **量化分**：实时计算显示在标签和交易面板
- **基准收益**：等权持有基准，对比你的操作
- **策略日志**：托管模式下显示每天策略判断

## 托管模式

选"纯量化S10"策略，每次推进日期自动交易：

| 条件 | 动作 |
|------|------|
| 量化分 > 68 | 全仓买入 |
| 量化分 < 35 | 清仓卖出 |

## 回测

```bash
# 单只回测
python backtest.py 600519 2019-01-01 2026-06-01 unified 500000

# 切换策略
python backtest.py 600519 2019-01-01 2026-06-01 s14 500000

# 批量测试15只股票
python batch_backtest.py
```

## 快捷键

- `→` 或 `空格`：推进1天

## 策略

| 策略 | 逻辑 | 回测结论 |
|------|------|------|
| S10 纯量化 | 量化>68买 <35卖 | 15股平均超额+49% |
| S14 均线交叉 | MA50金叉MA250买 | 跑输S10 |
| S15 回踩MA250 | 价触MA250买 | 跑输S10 |
| S16 最早入场 | 量化>60或MA交叉 | 接近S10 |
| S17 低门槛宽止损 | 量化>55买 -25%止 | 跑输S10 |
| S18 永持 | 量化>65买 不卖 | 等于S10 |
| S19 超早入场 | 量化>50买 不卖 | 等于S10 |

**结论**：没有单股择时策略能稳定跑赢持有不动。量化分用于选股，不用于择时。
